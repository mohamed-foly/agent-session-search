## Trademarks

The Claude Code and Codex marks belong to their owners (Anthropic and OpenAI).
The MIT licence on the icon files covers the artwork, not the trademarks. They
are used here only to identify which agent a session came from, small,
unmodified and never more prominent than this tool's own name. Anyone
redistributing this project commercially should check the owners' brand
guidelines, or replace the two logos (`agentIcons.ts` falls back to a neutral
icon for any agent without one).
